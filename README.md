# hf-download-tracker
Track daily download from Hugging Face platform

## TenK10K Multiome downloads

These counts are retrieved from the [Hugging Face dataset](https://huggingface.co/datasets/anglixue/TenK10K_multiome) daily at approximately 00:00 UTC and can also be refreshed manually using the workflow.
